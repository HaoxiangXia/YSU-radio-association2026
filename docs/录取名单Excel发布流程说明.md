# 「下载 Excel 模板 / 校验并预览 / 确认发布」是干嘛的？——大白话说明

## 一句话版本

招新结束后，负责人把「谁被录取了」填进一个 Excel 表格传给网站，网站核对没问题后正式发布，之后新生就能在「录取查询」页查到自己有没有被录取。

## 在哪儿

「招新设置与录取结果」页面（负责人登录后进入），页面下半部分「录取名单」卡片里的三个东西：

- **下载 Excel 模板** 按钮
- **选择文件** 框
- **校验并预览** 按钮

## 整个流程（就三步）

### 第一步：下载模板

点「下载 Excel 模板」，得到一个 `admission-template.xlsx`。

这个模板已经帮你把格式定死了：一个名叫「录取名单」的工作表，表头依次是：

| 姓名 | 学号 | 申请手机号 | 录取部门 |
|---|---|---|---|

里面还有一行示例（张三 / 202600000001 / 13800000000 / 嵌入式），照着填、把示例行换掉就行。模板带筛选和冻结首行，填几百行也不累。

两点说明：

- **没有「录取状态」列**——填进这张表的就是录取的，不用再标。
- **部门写简称就行**，比如「嵌入式」，不用写「嵌入式部门」。

> 为什么必须用模板？因为网站只认这个格式：工作表名字要对、表头顺序要对、不能多列少列。自己随便建个表传上去，九成九会被拒。

### 第二步：校验并预览

把填好的 `.xlsx` 选好，点「校验并预览」。网站会先当「质检员」把文件扒一遍：

- 文件是不是真 Excel（不能超过 2 MiB，不能是改了后缀名的假文件）
- 有没有宏、外部链接、公式（这些都不允许，防止有人夹带私货）
- 每一行格式对不对、学号有没有重复
- 总人数不能超过 2000 行

然后给你看两样东西：

1. **统计**：总计几条、已录取几条、未录取几条、错误几条（用新模板时「未录取」恒为 0，因为填进表的都是录取的）。
2. **预览表**：前 10 行的**脱敏**版本——姓名只显示姓（张\*\*），学号和手机号只露后 4 位；列为姓名、学号、申请手机号、录取部门。

> 为什么脱敏？预览只是让你确认「行数和大致内容对不对」，没必要把全体新生的完整手机号展示在屏幕上，少一次泄露机会。

有错就告诉你第几行错在哪（比如「第 5 行：学号重复」），**预览不会改动任何已发布的数据**，放心大胆试。

### 第三步：确认发布

校验全过后，「确认发布此名单」按钮才能点。点下去：

- 新名单替换旧名单，**旧名单会自动备份**（发错了还能找回来）；
- 发布完，录取查询**仍然保持关闭**，由你核对无误后手动打开。

> 一个硬性规定：如果「录取查询」正开着，发布按钮是禁用的。必须先关掉查询 → 发布新名单 → 复核 → 再打开。这是为了防止新生查到「一半新一半旧」的混乱名单。

## 查的人看到啥

新生在「录取查询」页输入**学号 + 当时申请填的手机号**，两个都对上才显示：姓名、录取部门、录取状态（新名单里大家都是「已录取」）。查不到就提示核对或联系负责人。

## 安全上做了啥（不用背，知道有就行）

- 只有登录的负责人能下载模板、预览、发布；
- 上传文件层层设防：大小限制、防 zip 炸弹、禁宏禁外链禁公式；
- 预览脱敏，完整数据不出现在浏览器里；
- 查询接口限流，防止有人拿脚本批量撞学号。

## 和「导出 CSV」别搞混

| | 方向 | 干啥 |
|---|---|---|
| 下载 Excel 模板 + 发布 | 你的电脑 → 网站 | 把录取结果**放进**网站 |
| 导出 CSV（申请管理页） | 网站 → 你的电脑 | 把入会申请**拿出**网站 |
