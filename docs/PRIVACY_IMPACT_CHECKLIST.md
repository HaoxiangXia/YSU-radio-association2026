# 招新个人信息保护上线确认表

> 本表用于社团内部上线确认，不替代学校制度或专业法律意见。不要在本文件中填写身份证号、手机号、密码、密钥或申请人资料。

## 数据和目的

系统收集姓名、学号、学院、年级、手机号码、电子邮箱、自我介绍和加入期望，用于接收入会申请、联系申请人、组织面试和核对录取结果。录取查询只返回姓名、录取部门和录取状态，不返回学号或手机号。

负责人上线前确认：

- [ ] 每个字段确有本次招新用途，没有“以后可能用到”但当前不必要的字段。
- [ ] 申请页已经说明处理目的、查看人员、联系方式和更正/删除渠道。
- [ ] 资料保留期限具体、合理，并已写入招新设置。

## 中国香港服务器存储

生产服务器位于中国香港。申请页设置两个独立确认：一般个人信息处理说明，以及香港服务器存储说明。两个布尔值仅用于阻止未确认的提交，不写入入会申请业务表。

- [ ] 负责人已经核对香港存储说明的主体、字段、用途、位置、接收人员、期限和申请人权利。
- [ ] 已确认是否还需要学校审批、内部备案或专业意见。
- [ ] 未使用默认占位文案直接开放正式申请。

## 访问和保护措施

- [ ] 负责人账号使用独立强密码，服务器只保存 PBKDF2 哈希。
- [ ] JWT 密钥、账号哈希、数据库、Excel、录取 JSON 和 CSV 均不在 Git 或公开目录。
- [ ] Uvicorn 只监听 `127.0.0.1:5000`，公网只经 Nginx HTTPS 访问。
- [ ] 负责人公共电脑不选择保持登录，操作完成后退出。
- [ ] 导出文件只进入批准的受限存储，未上传公开群文件或个人公开网盘。
- [ ] 自动备份、手动备份、恢复和回滚演练已经通过。

## 事件与到期处理

- [ ] 已指定发现误删、泄露、异常登录或错误名单时的联系人。
- [ ] 已演练关闭入会申请和录取查询。
- [ ] 已明确申请人查阅、更正、撤回同意和删除请求的处理方式。
- [ ] 到期清理必须先核对数据库、CSV、录取名单和备份范围，并由负责人明确批准。
